TROUBLESHOOTING:
----------------
Problem: Network error
Solution: Check both devices on same WiFi, verify IP in PosApi.kt

Problem: Code not found
Solution: Run database initialization again

Problem: APK won't install
Solution: Enable "Unknown Sources" in phone Settings → Security

Problem: Can't build APK
Solution: Android Studio → File → Invalidate Caches → Restart
