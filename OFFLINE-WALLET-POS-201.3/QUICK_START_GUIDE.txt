================================================================================
                    TROUBLESHOOTING
================================================================================

Problem: Network error
Fix: Check both devices on same WiFi, verify IP address in PosApi.kt

Problem: Code not found
Fix: Run database initialization again (script does this automatically)

Problem: APK won't install
Fix: Enable "Unknown Sources" in phone Settings → Security

Problem: Can't build APK
Fix: In Android Studio: File → Invalidate Caches → Restart
