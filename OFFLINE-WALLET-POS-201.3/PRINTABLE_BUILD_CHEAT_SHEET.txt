     4. Build:          Build → Build Bundle(s) / APK(s) → Build APK(s)
     5. Find:           app/build/outputs/apk/debug/app-debug.apk
     6. Copy:           To phone via USB
     7. Install:        Enable Unknown Sources → Tap APK → Install
