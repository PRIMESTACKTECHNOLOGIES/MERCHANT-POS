# Protocol 201.3 - Data Dictionary

## Transaction Fields Explanation

| Field | Description | Example |
| :--- | :--- | :--- |
| **`localTxnId`** | **Terminal-Side Unique ID** (Idempotency Key). Used to prevent duplicate transactions if re-uploaded. | `"TXN-0001"` |
| **`stan`** | **System Trace Audit Number**. A 6-digit number generated by the terminal for tracking. increments 000001-999999. | `"123456"` |
| **`amountMinor`** | **Transaction Amount in Minor Units**. No decimals. For AED (2 decimals), 15000 = 150.00. | `15000` |
| **`authMode`** | **Authorization Mode**. Indicates how the transaction was approved. <br>Values: `OFFLINE_APPROVED`, `OFFLINE_DECLINED`, `ONLINE_APPROVED`, `ONLINE_DECLINED`. | `"OFFLINE_APPROVED"` |
| **`emvData`** | **EMV Chip Data**. Optional for some, but critical for Chip cards to prove authenticity (Cryptogram). | `{ "tag_9F26": "..." }` |
