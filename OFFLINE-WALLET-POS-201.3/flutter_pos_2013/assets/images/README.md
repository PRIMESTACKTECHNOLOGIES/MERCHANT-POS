# Assets Folder

Place your app images here:

## Required Images

### Branding
- `logo_light.png` - Logo for light mode (transparent background)
- `logo_dark.png` - Logo for dark mode (transparent background)
- `logo_splash.png` - Splash screen logo (centered, any background)

### Icons
- `app_icon.png` - App launcher icon (1024x1024 recommended)

## Recommended Sizes

| Image | Size | Format |
|-------|------|--------|
| logo_light.png | 512x512 | PNG |
| logo_dark.png | 512x512 | PNG |
| logo_splash.png | 1024x1024 | PNG |
| app_icon.png | 1024x1024 | PNG |

## Tips

- Use transparent backgrounds for logos
- Keep file sizes under 500KB for faster loading
- Use PNG for best quality
- Consider using SVG for scalability (with flutter_svg package)
