╔══════════════════════════════════════════════════════════════════════════════════════════╗
║                              KEY CODES & REFERENCES                                       ║
╚══════════════════════════════════════════════════════════════════════════════════════════╝

   STAN (System Trace Audit Number): 6-digit code for tracking
   ├─ Example: 000042, 000043, 000044
   └─ Generated by: POS App (offline or online)

   Settlement Code: Gateway reference for batch
   ├─ Example: SETT-789123, SETT-456789
   └─ Generated by: Payment Gateway after processing

   Gateway Transaction ID: Individual transaction reference
   ├─ Example: bt_abc123, bt_def456 (Braintree)
   └─ Generated by: Payment Gateway

   Batch ID: Group of transactions
   ├─ Example: batch-20260308-001
   └─ Generated by: POS App or Backend

   ├─ GET  /merchant/v1/batches                  (View batches)
   ├─ POST /merchant/v1/cashout/braintree        (Cashout to gateway)
   └─ POST /merchant/v1/payments/charge          (Direct charge)
