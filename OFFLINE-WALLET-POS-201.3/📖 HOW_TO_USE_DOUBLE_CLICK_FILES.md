# 🖱️ Double-Click Files - No Typing Needed!

## 📦 What You Got

I created **5 batch files** in your `POS OFFLINE SFTWR` folder.

Just **double-click** them - no typing, no terminal commands!

---

## 🚀 The Files

### 1. 🚀 START_EVERYTHING.bat ⭐ **USE THIS ONE!**
**What it does:**
- Opens backend server (port 3000)
- Waits 5 seconds
- Opens dashboard (port 5173)
- Opens browser automatically

**When to use:** Every time you want to use the POS system

**Double-click → Wait → Browser opens automatically!**

---

### 2. 🚀 START_BACKEND.bat
**What it does:**
- Opens backend server only
- Runs on http://localhost:3000

**When to use:** If you only need the backend API

---

### 3. 🚀 START_DASHBOARD.bat
**What it does:**
- Opens dashboard only
- Opens browser automatically
- Runs on http://localhost:5173/

**When to use:** If backend is already running

---

### 4. 🚀 CHECK_STATUS.bat
**What it does:**
- Checks if everything is installed
- Checks if ports are free
- Shows ✓ or ✗ for each component

**When to use:** Before starting, to check if ready

---

### 5. 🚀 FIX_NPM_INSTALL.bat
**What it does:**
- Installs all npm packages
- Fixes missing dependencies
- Clears cache

**When to use:** If you see "module not found" errors

---

## 🎯 Quick Start (3 Steps)

### Step 1: First Time Setup
```
Double-click: 🚀 FIX_NPM_INSTALL.bat
```

## 🆘 Troubleshooting

### "Windows protected your PC"
**Fix:** Click "More info" → "Run anyway"

### "Command not found"
**Fix:** Run 🚀 FIX_NPM_INSTALL.bat first

### "Port already in use"
**Fix:** Restart computer, then try again

### Browser doesn't open
**Fix:** Manually go to http://localhost:5173/
